# Book Analysis Web Application

A web application for analyzing book reading data and predicting which books to drop for improved utility.

## Overview

This application allows users to upload their book reading history CSV and get predictions on how their enjoyment and usefulness would improve by dropping the lowest-rated books according to various ML models.

## Files

### Core Application
- **`index.html`** - Main HTML structure with accessibility features
- **`app.js`** - Main application logic, CSV processing, chart rendering
- **`predict.js`** - Pure prediction functions for RF, GBM, and Ridge models
- **`style.css`** - Styling with glassmorphism effects and responsive design
- **`models.json`** - Exported ML models (881KB, generated by `export_models_for_extension.py`)

### Testing
- **`tests.js`** - Node.js unit and integration tests for all functions

### Data Files (for testing/validation)
- `gwern_books*.csv` - Scraped book data
- `mcp_scraper_*.json` - MCP scraper cache files

### Scraper Scripts (development only)
- `get_gwern_books.py` - Scrape book lists
- `fetch_gwern_rich.py` - Enrich with metadata
- `gwern_analysis.py` - Analyze scraped data
- `verify_gwern_csv.js` - Validation script

## Usage

### CSV Format

Your CSV must include these columns (exact names or variants):

**Required for predictions:**
- `goodreads_rating` (or `goodreads_rating_raw`, `GR`)
- `amazon_rating` (or `amazon_rating_raw`, `AMZ`)
- `avg_enjoyment` (or `enjoyment`) - your rating for enjoyment
- `avg_usefulness` (or `usefulness`) - your rating for usefulness

**Optional enrichment:**
- `goodreads_rating_count` (or `goodreads_rating_count_raw`)
- `amazon_review_count_consensus`
- `page_count` (or `pages`)
- `pub_year` (or `original_publication_year`, `year`)
- `Bookshelf` (or `category`) - book category/genre
- `title` (or `Title`)

### How It Works

1. **Upload**: Drag and drop your CSV or click to browse
2. **Validation**: App validates data has required columns and ratings
3. **Processing**: 
   - Extracts features from each book
   - Runs predictions using RF, GBM, and Ridge models
   - Calculates drop curves for 0-95% drop rates
4. **Visualization**:
   - Shows baseline enjoyment/usefulness
   - Charts showing utility gain vs drop percentage
   - Compares Oracle (perfect), ML models, and simple heuristics

### Models

The application uses four prediction strategies:

1. **Oracle (Perfect Sort)** - Upper bound using true ratings
2. **Ridge Regression** - Linear model with group-specific rating imputation
3. **Random Forest** - Ensemble of 100 decision trees
4. **Simple Heuristic** - GR + AMZ rating sum threshold

All models predict on 1-5 scale and are trained on 200+ historical books.

## Architecture

### Data Flow

```
CSV Upload → Parse → Validate → Extract Features
                                      ↓
                              Run Predictions
                                      ↓
                         Calculate Drop Curves
                                      ↓
                            Render Charts
```

### Prediction Pipeline

Each book goes through:
1. Feature extraction (ratings, counts, metadata)
2. Category mapping for group-specific models
3. Rating imputation using cross-source regression
4. Parallel predictions from all models
5. Conformal prediction intervals (50%, 85%)
6. Percentile rank calculation

### Chart Generation

Uses Chart.js to render:
- Line charts with 4 strategies per outcome
- X-axis: Drop percentage (0-95%)
- Y-axis: Rating gain vs baseline
- Interactive tooltips and legends
- Responsive design for mobile
